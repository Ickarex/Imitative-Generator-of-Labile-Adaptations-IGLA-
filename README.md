# Imitative-Generator-of-Labile-Adaptations-IGLA-
Репозиторий, содержащий все материалы по проекту АСУ-2608 ТУСУР

Предполагаемый формат работы:
Каждый работает над своей задачей, каждую неделю-две, на паре обсуждаем и советуемся. Раз в месяц небольшой отчет о проделанной работе, отчеты называть в следующем виде: "ФИО_задача(текстом)_отчетный период(номер)". По поводу отчетов сильно чего-то требовать не буду, просто вкратце изложить суть задачи, описать решение, приложить листинг. По оформлению стандартный отчет по лабам без придирок к ос тусур. К каждой кт будет составляться приблизительная версия финального отчета. Для каждой модели будет отдельная директория, куда нужно кидать файлы, связанные с работой моделей. Доки кидать в отдельную папку независимо от модели и задачи. Было бы хорошо сделать автофиксацию успешных адаптаций и автоматический перезапуск симуляции при образовании успешной колонии или вымирании (над этим еще подумаем).
